# 📄 AI Doc Reader

**AI Doc Reader** is an AI-powered document reading and analysis application that helps users understand lengthy documents quickly and easily. Users can upload documents such as PDFs, notes, assignments, and other text-based files, and the application uses Artificial Intelligence to analyze the content.

## 🚀 Features

* 📤 Upload documents
* 🤖 AI-powered document analysis
* 📝 Generate document summaries
* 🔍 Ask questions about the uploaded document
* 💡 Extract important information and key points
* 📚 Helpful for students, teachers, and professionals
* ⏱️ Saves time when reading lengthy documents
* 🖥️ Simple and user-friendly interface

## 🎯 Objective

The main objective of **AI Doc Reader** is to make document reading faster, easier, and more interactive. Instead of manually reading a long document, users can use AI to summarize the content and find important information quickly.

## 🛠️ Technologies Used

* **Python**
* **Streamlit**
* **Generative AI / Gemini API**
* **PDF/Text Processing**
* **HTML & CSS** for interface customization

## ⚙️ How It Works

1. Open the AI Doc Reader application.
2. Upload a PDF or supported document.
3. The application reads and processes the document.
4. AI analyzes the document content.
5. Users can generate a summary or ask questions.
6. The application provides relevant answers based on the uploaded document.

## 💻 Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/AI-Doc-Reader.git
```

### 2. Open the project folder

```bash
cd AI-Doc-Reader
```

### 3. Install required libraries

```bash
pip install -r requirements.txt
```

### 4. Add your API key

Create a `.env` file and add your Gemini API key:

```text
GEMINI_API_KEY=your_api_key_here
```

**Never upload your API key or `.env` file to GitHub.**

### 5. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.
